# YouTube Ambient Lights

Bring a cinematic ambient glow to your YouTube viewing experience!

YouTube Ambient Lights is a lightweight Firefox extension that creates a soft, blurred glow around the YouTube video player, inspired by the colours of the video you're watching.

## Features

- **Ambient Background:** Adds a beautiful glow around the YouTube video player.
- **Automatic Colour Mode:** Matches the glow to video colours where supported.
- **Manual Colour Mode:** Choose your own ambient colour.
- **Blur Intensity:** Adjust how soft or sharp the glow looks.
- **Glow Intensity:** Control the brightness of the ambient effect.
- **Glow Size:** Adjust how far the glow spreads.
- **In-Player Settings:** Control the effect directly from the YouTube player.
- **Saved Preferences:** Your settings are remembered.

## Installation Guide

### Method 1 — Install from Firefox Add-ons (Recommended)

The easiest way to install:

1. Visit the official Firefox Add-ons page:
   https://addons.mozilla.org/en-US/firefox/addon/youtube-ambient-background/
2. Click **Add to Firefox**.
3. Confirm the installation.
4. Open YouTube and play a video.
5. Enjoy your ambient lighting!

### Method 2 — Install Locally from GitHub

For users who want to download and try the extension files:

1. Open this GitHub repository.
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP.
5. Open Firefox and visit `about:debugging#/runtime/this-firefox`.
6. Click **Load Temporary Add-on**.
7. Select the `manifest.json` file inside the extracted folder.
8. Open YouTube and test the extension.

**Note:** Local installation through `about:debugging` is temporary. Firefox may remove the temporary add-on after a restart. For regular use, install it from the official Firefox Add-ons page.

## How to Use

1. Open YouTube and play any video.
2. Find the YouTube Ambient Lights button in the video player.
3. Open its settings panel.
4. Enable or disable the ambient effect.
5. Adjust blur intensity, glow intensity and glow size.
6. Choose automatic or manual colour mode.
7. Enjoy your customised viewing experience!
